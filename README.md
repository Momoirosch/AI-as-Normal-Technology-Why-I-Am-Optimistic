# AI as Normal Technology – Why I Am Optimistic

A simple, responsive GitHub Pages page containing the original blog text from the PDF.
The wording is preserved; PDF line wraps and page breaks are removed, and references are clickable.
No dependencies or build step are needed. Open `index.html` to preview it.

## Publish with GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select **main** and **/ (root)**, then click **Save**.

GitHub will publish the page at:
https://momoirosch.github.io/AI-as-Normal-Technology-Why-I-Am-Optimistic/

To update the article, edit `index.html` and commit the change to `main`.
